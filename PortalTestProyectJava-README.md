# PortalTestProyectJava

Proyecto de prueba en Java (Eclipse), creado para practicar.

Contiene una sola clase, `Empleado`, en `TestProyectoJava/src/org/modelo/empleado/`, que imprime un mensaje en consola.

## Estructura

- `TestProyectoJava/src/org/modelo/empleado/Empleado.java` — clase de ejemplo
- Archivos de configuración de Eclipse (`.classpath`, `.project`, `.settings/`)
